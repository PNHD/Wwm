# Map sources and provenance

WWM Atlas does not claim ownership of third-party map content.

## Official Map

Provider: Where Winds Meet / official game website.
URL: `https://www.wherewindsmeetgame.com/map/en/`
Role: primary real map source.

## 17173 CN

Provider: 17173, described publicly as an official cooperation map site for the Chinese game community.
URL: `https://map.17173.com/yysls/maps/qinghe`
Role: Chinese fallback with dense POI coverage.

## MapGenie

Provider: MapGenie.
URL: `https://mapgenie.io/where-winds-meet/maps/world`
Role: English fallback.

## Bundled demo dataset

`data/qinghe-demo.geojson` and `assets/map-placeholder.svg` are synthetic UI fixtures only. They do not represent real in-game coordinates or game artwork.
